# HireReady — HTML + CSS Job Portal Frontend

## 📘 Project Overview

HireReady is a responsive job portal frontend built using only HTML5 and CSS3.

This project simulates a real-world hiring platform like LinkedIn or Indeed and focuses on:

- Real-world UI layout
- Responsive design
- Clean HTML & CSS structure
- Professional folder organization

---

## 🛠 Tech Stack

- HTML5
- CSS3

❌ No JavaScript  
❌ No Bootstrap / Tailwind / CSS frameworks  

---
